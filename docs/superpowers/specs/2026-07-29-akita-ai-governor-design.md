# AI Governor Lab 秋田 — 設計仕様書

作成日: 2026-07-29

## 1. 目的

「AI が秋田県知事だったら何をするか」を、価値観の重み付けを変えながら探索できる Web アプリを作る。
あわせて、47 都道府県の歳入・歳出構造と産業構造を公的統計で比較できるデータセクションを同一アプリ内に持たせ、
シミュレーション結果の根拠として参照できるようにする。

本アプリは思考実験であり、現実の秋田県および県政に対する評価・提言ではない。

## 2. スコープ

### 含むもの

- 5 軸の価値観スライダーによる施策パッケージ生成（決定論的・ブラウザ内計算）
- 事前執筆した施策カード約 50 枚のプール
- 47 都道府県の歳入内訳・目的別歳出・性質別歳出の比較ビュー
- 47 都道府県の経済活動別県内総生産（産業構造）の比較ビュー
- 前提・免責・出典ページ
- 公的統計 Excel を JSON に変換する取り込みスクリプト（手動実行）

### 含まないもの

- 実行時の LLM API 呼び出し（全出力は事前生成・静的）
- データベース、認証、ユーザーデータの永続化
- サーバーサイドの動的処理（静的エクスポートのみ）
- 市区町村レベルのデータ

## 4. データ

### 4.1 出典

| データセット | 出典 | 取得方法 | 年度 |
|---|---|---|---|
| 歳入内訳・性質別歳出・目的別歳出 | 総務省「令和5年度都道府県財政指数表」第7章 都道府県別資料 | `https://www.soumu.go.jp/main_content/0009992{30..76}.xlsx`（47 ファイル、JIS コード順。北海道=000999230、秋田県=000999234） | 令和5年度 |
| 経済活動別県内総生産（名目） | 内閣府 経済社会総合研究所「県民経済計算」主要系列表1 | `https://www.esri.cao.go.jp/jp/sna/data/data_list/kenmin/files/contents/tables/2022/syuyo1.xlsx` | 平成23〜令和4年度 |

いずれも政府標準利用規約（第2.0版、CC BY 4.0 互換）に基づき、出典明記の上で利用する。

取得可能性は検証済み。総務省ファイルは 1 ファイル 3 シート構成で、
シート1「収入の状況」、シート2「性質別歳出の状況」、シート3「目的別、性質別歳出及び充当財源の状況」を含む。
内閣府 `syuyo1.xlsx` は年度ごとに 12 シートを持ち、各シートに 47 都道府県 × 16 業種の名目県内総生産を含む。

### 4.2 取り込みパイプライン

`scripts/` 配下のスクリプトは**手動実行**する。Vercel のビルド時には実行しない。
理由は、外部サイトへの依存をデプロイのクリティカルパスから外すため、および出力を人がレビューしてからコミットするため。

```
scripts/fetch-fiscal.ts    → src/data/fiscal.json
scripts/fetch-industry.ts  → src/data/industry.json
```

生成された JSON はリポジトリにコミットする。

### 4.3 データ形状

```ts
// fiscal.json
type Fiscal = {
  meta: { fiscalYear: string; source: string; license: string; fetchedAt: string };
  prefectures: Array<{
    code: string;              // "05"
    name: string;              // "秋田県"
    revenue: Record<string, number>;   // 道府県税, 地方交付税, 国庫支出金, 地方債 ...（人口1人当たり円）
    expenseByPurpose: Record<string, number>;  // 民生費, 土木費, 教育費, 公債費 ...
    expenseByNature: Record<string, number>;   // 人件費, 扶助費, 普通建設事業費 ...
    totals: { revenue: number; expense: number };
  }>;
};

// industry.json
type Industry = {
  meta: { fiscalYear: string; source: string; license: string; fetchedAt: string };
  sectors: string[];           // 農林水産業, 鉱業, 製造業, ... 16 業種
  prefectures: Array<{
    code: string;
    name: string;
    gdpBySector: Record<string, number>;   // 単位: 100万円
    primary: number; secondary: number; tertiary: number;
  }>;
};

// policies.json（全文を事前執筆）
type Policy = {
  id: string;
  name: string;
  summary: string;
  costOku: number;                  // 億円/年
  expenseCategory: string;          // 対応する目的別歳出区分
  scores: {                         // -10 〜 +10
    population: number; economy: number; fiscal: number;
    quality: number; durability: number;
  };
  rationale: string;                // 採択理由（事前執筆）
  sideEffects: string[];            // 副作用（事前執筆）
  evidence: { label: string; url: string }[];  // 参照した公的統計
  exclusiveGroup?: string;          // 相反施策の排他グループ
  horizon: 'short' | 'medium' | 'long';
};
```

## 5. シミュレーターの設計

### 5.1 価値観の軸

| キー | 表示名 | 副題 |
|---|---|---|
| `population` | 人口増加 | 社会増減・出生数を伸ばす |
| `economy` | 経済成長 | 県内総生産・所得を伸ばす |
| `fiscal` | 財政健全化 | 将来世代の負担を減らす |
| `quality` | 生活の質 | 医療・教育・安全を守る |
| `durability` | 政治的持続性 | 再選可能性をどれだけ重視するか |

各軸 0〜100。`durability` には公共選択論の説明ツールチップを常設する（詳細は §7）。

### 5.2 選定アルゴリズム

決定論的かつブラウザ内で完結する。同じ入力からは常に同じ出力が出る。

```
1. 各カードのスコアを計算
     score(card) = Σ_axis (weight[axis] / 100) × card.scores[axis]
2. score 降順にソート
3. 上から走査し、exclusiveGroup が既出のカードはスキップ
4. 予算上限（秋田県の実際の一般会計歳出規模の 3% を「裁量枠」とする）に達したら打ち切り
5. 採択カードの costOku 合計を、目的別歳出構成比に応じて既存歳出から按分削減し「財源」として表示
6. 採択されなかった上位カードを「切られた施策」として別枠表示
```

裁量枠を歳出規模の 3% とするのは、地方財政において単年度で組み替え可能な範囲がごく限られるという制約を
モデルに反映させるため。この数値はモデルの仮定であり、画面上でもそう明示する。

### 5.3 人格プリセット

スライダーの初期値をセットするボタンとして提供する。独立した機能ではない。

- 人口最優先型 / 経済成長優先型 / 財政規律型 / 生活の質優先型 / 政治的持続性重視型 / バランス型

### 5.4 結果画面の構成

1. 施政方針文 — 採択カードから組み立てる。文面のパーツは全て事前執筆
2. 採択された施策カード — 理由・財源・副作用・出典を表示
3. 切られた施策 — 何を諦めたかを可視化
4. 歳出構成の変化 — 秋田県の実構成比 → シミュレーション後
5. 指標のトレードオフ — 4 年後 / 30 年後。「本モデルの仮定値」と明示

## 6. データセクションの設計

### 6.1 歳入構造

- 散布図: 地方税依存度（横）× 地方交付税依存度（縦）。47 県をプロットし秋田をハイライト
- 積み上げ棒: 任意 2 県の歳入内訳比較

### 6.2 歳出構造

- 目的別歳出の構成比を 47 県横並び（ヒートマップまたはソート済み積み上げ棒）
- 性質別歳出（人件費・扶助費・公債費・普通建設事業費）の構成比比較
- 全国平均との乖離を秋田について明示

### 6.3 産業構造

- 第1次/第2次/第3次産業の構成比 47 県比較
- 16 業種別の県内総生産構成、全国平均との乖離
- 2011〜2022 年度の推移

全チャートで秋田を常時ハイライトし、任意の 1 県を選んで並列比較できるようにする。

## 7. 法的リスクへの対応

本アプリは実在の自治体名を含み、政治的判断を主題とするため、以下を実装として組み込む。

1. **免責の常設** — 全ページのフッターに「本アプリは架空の AI モデルによる思考実験であり、現実の秋田県および県政、
   ならびに特定の個人・団体とは一切関係がありません」を表示。初回訪問時のみ前提説明モーダルを出す。
2. **固有名詞の排除** — 施策カードおよび全 UI 文言に、実在の人物名・政党名・企業名・団体名を含めない。
   禁止語リストによる機械チェックを CI（GitHub Actions）に組み込み、混入時はビルドを失敗させる。
3. **断定の回避** — 指標変化を「予測」と表現しない。「本モデルの仮定値」と明記し、算出根拠を開示する。
4. **政治的持続性軸の学術的フレーミング** — 公共選択論（Downs, Buchanan & Tullock）における
   「再選を目的関数に含む合理的主体としてのモデル化」であることをツールチップで常設説明し、
   特定人物の評価ではなく制度設計のための分析枠であると明示する。
5. **実在の選挙・候補者・政党の除外** — 現実の選挙、特定の候補者、政党、投票行動、世論・支持率に関する言及や示唆を
   一切含めない（公職選挙法上の疑義を避けるため）。禁止語リストで機械的に検査する。

   一方、公共選択論における「再選を目的関数に含む合理的主体」という**抽象的な分析概念**は本アプリの中核であり、
   除外の対象ではない。公職選挙法が規律するのは特定の選挙における特定候補者への支持・反対の働きかけであって、
   政治過程を説明するための一般的な理論枠組みではない。したがって「政治的持続性」軸の副題
   「再選可能性をどれだけ重視するか」およびそのツールチップの文言はこの制約に抵触しない。
   `再選` を禁止語リストに含めてはならない。
6. **出典とライセンスの明記** — `/about` に全データの出典 URL、年度、政府標準利用規約に基づく利用である旨を記載。

## 9. テスト方針

| 対象 | 方法 |
|---|---|
| 選定アルゴリズム | ユニットテスト。既知の重み入力に対する採択カード集合と予算合計を検証 |
| 排他グループ | 相反カードが同時採択されないことを検証 |
| 予算制約 | 採択カードの合計コストが裁量枠を超えないことを検証 |
| データ整合性 | fiscal.json / industry.json が 47 件揃い、構成比の合計が許容誤差内に収まることを検証 |
| 禁止語チェック | policies.json と UI 文言に禁止語が含まれないことを検証 |
| 取り込みスクリプト | 固定の入力 Excel に対する出力 JSON のスナップショット |

## 10. 決定事項の記録

- A（シミュレーター）と B（都道府県データ）は単一アプリに統合する
- 推論は実行時 LLM ではなく、事前執筆コンテンツ＋決定論的スコアリングで行う
- コンテンツは施策カードプール方式とし、スライダーは連続値のまま扱う
- 「自己保身」は「政治的持続性」として公共選択論の枠組みで提示する
- リポジトリは Public
